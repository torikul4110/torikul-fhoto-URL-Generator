# 🖼️ TORIKUL IMAGE • LINK • QR SYSTEM v5.0

A complete image and link management system with QR code generation, powered by Supabase and Cloudinary.

## 🚀 Features

- 📸 Single Image Upload → URL + QR (Stored in Cloudinary)
- 📸📸 Multiple Images → Group + URL + QR (Stored in Cloudinary)
- 🔗 Single Link → QR (Stored in Supabase)
- 🔗🔗 Multiple Links → Link Group + QR (Stored in Supabase)
- 📁 Unlimited Groups
- ➕ Add More to Existing Groups
- 🆔 All URLs have 'torikul' in ID
- 👁️ Group Gallery View
- 🖼️ Single Image View with Actions
- ✅ Persistent Storage: Supabase + Cloudinary

## 🔧 Environment Variables

| Variable | Description |
|----------|-------------|
| `SUPABASE_URL` | Your Supabase project URL |
| `SUPABASE_KEY` | Your Supabase anon key |
| `CLOUDINARY_CLOUD_NAME` | Your Cloudinary cloud name |
| `CLOUDINARY_API_KEY` | Your Cloudinary API key |
| `CLOUDINARY_API_SECRET` | Your Cloudinary API secret |
| `ADMIN_USERNAME` | Admin login username |
| `ADMIN_PASSWORD` | Admin login password |
| `SECRET_KEY` | Flask secret key |

## 🚀 Deployment

1. Push to GitHub
2. Import to Vercel
3. Set Environment Variables
4. Deploy!
